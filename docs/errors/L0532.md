# L0532: refused in a sandboxed build

<!-- rustc-wrong: pass -->
<!-- lust-args: --sandbox -->

The build used `--sandbox`, and the program reaches an OS service the
sandbox refuses. A sandboxed program may read stdin and write stdout and
stderr; it may not use the file system, the network, the environment,
processes, OS extensions, or threads, and `include!`, `include_str!` and
`include_bytes!` read no file. Check refuses the std paths to those
services in your source. A path check cannot see every route (`Path::exists`
reads the file system), so the built program also stops with this code,
exit status 101, before such a call runs.

Pass the data in on stdin and answer on stdout. The mode is for running
code a tool or a model wrote; see `docs/sandbox.md`.

## Wrong

```rust
fn main() {
    let text = std::fs::read_to_string("input.txt").unwrap_or_default();
    println!("{}", text.len());
}
```

## Fixed

```rust
use std::io::Read;

fn main() {
    let mut text = String::new();
    std::io::stdin().read_to_string(&mut text).unwrap();
    println!("{}", text.len());
}
```
