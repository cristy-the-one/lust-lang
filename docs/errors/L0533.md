# L0533: ran past a time limit

<!-- rustc-wrong: pass -->
<!-- runtime-stop -->
<!-- lust-args: --sandbox --time-limit 300ms -->

The build used `--sandbox --time-limit`, and the program ran longer than
that limit. The limit is built into the program. A loop checks it on every
back-edge, a function entry checks it every 64th call, and `thread::sleep`
does not sleep past it. The program prints this line on stderr and exits
with status 101. What it printed before that is flushed first.

A check does not run the program, so this code is not a check error. The
source below is valid Rust. It fails when the built program runs.

Pass a duration the program can finish inside, or make the program finish.
The host should still kill a program that runs too long: a straight-line
body that never loops, calls, or sleeps is not probed. See `docs/sandbox.md`.

## Wrong

```rust
fn main() {
    loop {}
}
```

## Fixed

```rust
fn main() {
    println!("done");
}
```
