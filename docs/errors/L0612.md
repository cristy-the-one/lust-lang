# L0612: no impl of the trait for this type

A bound or call needs a trait impl that does not exist for
this type. Selection matched the whole trait reference and
found no candidate. Add the impl, or change the bound.

The message includes the trait's input arguments. For example,
`no impl of From<&String> for Json` means the missing conversion
is from a borrowed `String`. If `Json` implements `From<String>`,
pass the owned string instead (or clone it if you still need it).

The same code reports a `'static` bound that does not hold: a
type parameter without a `'static` bound used where one is needed
(rustc E0310), or an impl of a trait bounded by `'static` (`trait
Tr: 'static`) for a type with a reference or a parameter that is
not `'static`.

## Wrong

```rust
trait Tr {
    fn v(&self) -> u8;
}

struct S;

fn call<T: Tr>(v: &T) -> u8 {
    v.v()
}

fn main() {
    println!("{}", call(&S));
}
```

## Fixed

```rust
trait Tr {
    fn v(&self) -> u8;
}

struct S;

impl Tr for S {
    fn v(&self) -> u8 {
        1
    }
}

fn call<T: Tr>(v: &T) -> u8 {
    v.v()
}

fn main() {
    println!("{}", call(&S));
}
```
